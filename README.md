# Information Technology Security & Administration (ITSA): Operating Systems I

This repository contains lab exercises, shell scripts, and configuration documentation developed during the **Operating Systems I** course within the Information Technology Security and Administration (ITSA) program at MyComputerCareer[cite: 1, 2].

It demonstrates practical competencies in Linux system administration, permission management, task automation using Bash and Python, and environment configuration in PowerShell.

---

## 🛠️ Technical Skills Demonstrated

### 1. File Systems & Access Control
* **Navigation & Troubleshooting:** Utilized absolute and relative paths along with command-line tools (`cd`, `pwd`, `ls`, `cat`, `less`, `tail`) to inspect and troubleshoot file access issues.
* **Permissions & Security:** Configured file ownership and group access controls using `chown`, `chgrp`, and `chmod` to maintain secure multi-user environments.

### 2. Automation & Scripting
* **Bash Shell Scripting:** Automated routine command-line tasks and administrative workflows using structured Bash scripts.
* **Python Development:** Built interactive scripts utilizing variables, data types, operators, and user I/O functions[cite: 2].
* **PowerShell Workflows:** Configured and customized administrative environments across PowerShell Console, ISE, and Visual Studio Code to streamline scripting workflows[cite: 2].
